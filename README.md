# Al Hafsa

Premium responsive Next.js landing website with Framer Motion animations.

## Run locally
1. Install Node.js 20+.
2. Run `npm install`
3. Run `npm run dev`
4. Open http://localhost:3000

## Deploy to Vercel
Import this folder/repository into Vercel. Framework: Next.js. Build command: `npm run build`.

No database or paid API is required.
